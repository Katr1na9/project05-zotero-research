# Project05 Asset Ownership Matrix

## 路由矩阵

| 新产物 | 共享区 | P05-L1 | P05-L2 |
|---|---:|---:|---:|
| 单篇论文全文精读 | 是 | 否 | 否 |
| 跨线 Zotero 元数据/去重记录 | 是 | 否 | 否 |
| 通用精读/实验/审稿模板 | 是 | 否 | 否 |
| 某论文线的 RQ Brief | 否 | 是 | 是 |
| 某论文线的撞题矩阵 | 否 | 是 | 是 |
| 某论文线的主题综合笔记 | 否 | 是 | 是 |
| 数据预注册与实验代码 | 否 | 是 | 是 |
| 论文草稿与 Reviewer 回复 | 否 | 是 | 是 |
| 可跨线复用的数据 schema | 评审后 | 首发线保留来源 | 首发线保留来源 |

## 晋升为共享资产的条件

线内资产只有同时满足以下条件，才可晋升到共享区：

1. 不包含该论文特有的结论或隐藏答案键；
2. 至少被两条研究线实际复用，而不是推测未来可能复用；
3. 有明确版本和来源研究线；
4. 迁移后不会破坏预注册哈希或实验复现路径。

## 禁止事项

- 不复制同一精读笔记到两条研究线；
- 不把 P05-L1 的结论自动继承为 P05-L2 的研究假设；
- 不共享盲标管理员 key、原始大数据或含敏感路径的本地文件；
- 不因目录整理改写历史实验事实。
