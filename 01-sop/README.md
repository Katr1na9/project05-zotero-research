# Project05 Shared SOP

本目录保存所有研究线共享的科研、Zotero、精读和工作区治理流程。

- `project05-multi-line-workspace-sop-v0.1.md`：多论文线目录与所有权规则；
- `project05-skill-driven-workflow-v2.md`：Project05 阶段化研究流程；
- `research-workflow-sop.md`：日常科研推进；
- `zotero-literature-management-sop.md`：Zotero 管理。

论文线特有流程应放在该线自己的 `01-sop/`，不得修改共享 SOP 来迎合单篇论文的临时需求。
