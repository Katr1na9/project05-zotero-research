## 1. 实验规模

- 独立参数环境：`192`
- 每个环境配对 seed：`10`
- 策略：一步 gain/cost、冻结 M2、Depth-2+M2、DP Oracle
- 总 episode：`7,680`
- 环境维度：解锁深度、预算余量、诱饵数量、诱饵即时收益、链路可靠性

重复 seed 是同一环境的随机实现，不扩张独立环境数。

## 2. 总体结果

| Planner | Success | 成功条件均成本 | Premature STOP | 局部收益 |
|---|---:|---:|---:|---:|
| One-step gain/cost | 0.0000 | - | 0.1250 | 3.4635 |
| 冻结 M2 | 0.0948 | 3.0000 | 0.2333 | 1.5094 |
| Depth-2 + M2 | 0.3708 | 3.1770 | 0.0766 | 1.1589 |
| DP Oracle | 0.7156 | 3.4367 | 0.0000 | 0.0000 |

一步策略获得最高局部收益却从未达到目标，说明局部证据增益与最终归因目标可以系统性错位。DP 不采集诱饵，因此局部收益为 0，但目标成功率最高。

## 3. Gate A：非短视必要性

**通过。**

- 可达独立环境：`192`
- 出现 DP 相对 M2 明显优势的冲突环境：`166`
- DP 相对 M2 的平均 success 优势：`0.6208`
- 解锁深度 1 上 Depth-2 相对 M2 的修复：`0.4000`
- 冲突覆盖全部诱饵数量 `1/3/6/10` 和全部即时收益 `0.5/1.0/2.0`

这证明在所定义的主动取证环境族中，“先做低即时收益解锁动作”具有稳定必要性。它不估计真实攻击调查中此类状态的发生率。

## 4. Gate B：DQN 必要性

**不通过。**

- DP 相对 Depth-2 的 success 优势：`0.3448`
- 深度 2/3/4 的 success gap：`0.3625/0.3417/0.6750`
- DP 冷启动中位耗时：`0.7692 ms`
- DP 冷启动 p95：`83.9598 ms`，低于 `100 ms` 阈值
- 最大状态展开数：`23,892`，低于 `100,000` 阈值

Depth-2 确实不足，但当前规模下完整 DP 仍可承受。因此正确结论是“需要更深规划”，不是“需要 DQN”。

## 5. 当前决策

```text
Gate A: PASS
Gate B: FAIL
Decision: use_lightweight_nonmyopic_planning_no_dqn
```

论文/专利主线继续使用现有证据缺口建模、预算门控和负结果边界。轻量非短视规划可作为方法增强或附录实验；DQN/Dueling DQN 不进入当前主模型。

## 6. 限制

- 环境是结构化存在性诊断，不是真实攻击发生率样本。
- DP Oracle 知道完整转移概率，只是规划上界。
- 运行时间依赖硬件；状态展开数是更稳定的复杂度指标。
- XGBoost 未直接放入人工环境，因为它在 C01-C06 上训练，直接迁移会把规划深度与分布外表示混为一谈。
- 该结果不能写成“RL 无效”，只能写成“当前规模下没有启动 DQN 的必要证据”。
