## 1. 发明名称（草案）

一种基于对齐感知证据缺口状态的成本约束取证动作规划方法及系统

## 2. 要解决的技术问题

在 APT 归因中，CTI 行为图与本地证据仅部分对齐时，现有系统或直接输出 actor，或只给出缺失证据列表，缺乏在成本约束下依据**当前缺口节点**选择取证动作、并在证据不足时**停止/降级**的机制。

## 3. 独立权利要求方向（方法）

一种取证动作规划方法，其特征在于包括：

1. 获取 CTI 侧攻击行为图与本地观测证据的对齐结果，构建可更新的**证据缺口状态**，所述状态至少包括：已覆盖行为节点、未匹配关键节点、以及当前可支撑的归因粒度等级；
2. 维护候选取证动作集合，每一动作具有公开的**意图目标节点集合**、采集通道标识与成本；所述意图目标节点集合独立于动作实际可恢复证据集合进行声明；
3. 根据当前未匹配节点与动作意图目标节点的兼容性，在剩余预算约束下选择下一取证动作；当无正收益动作时选择**停止动作**并输出当前可支撑归因粒度；
4. 执行所选动作后，依据采集通道的实现结果更新证据缺口状态与可支撑粒度，并重复步骤 3，直至达到目标粒度、预算耗尽或停止。

## 4. 从属权利要求方向（可组合）

- 兼容性评分显式加权**关键缺口命中**、意图精确率/召回率与成本（对应 M3a）。
- 采集通道具有预登记可靠性；通道离线时动作可不恢复证据，且规划仅使用公开先验与执行后反馈，不读取隐藏可恢复集合。
- 当在实现通道状态下目标粒度不可达时，停止判定为**降级停止**，并与可达性下界一致。
- 归因粒度包括 technique / tactic-intent / campaign 等有序等级，且输出不超过证据支持上限。
- 系统实施例：状态存储、动作库、规划模块、通道门控执行模块、停止/降级输出模块。

## 5. 明确不写入主权利要求的内容

- 具体 CTI–provenance 图对齐算法本身；
- 端到端 APT actor 分类准确率；
- 泛化的“大模型多轮拉取任意数据直至置信”；
- 将取证过程宽泛表述为 MDP/RL 求解（避免与 WinRegRL 等过宽撞车；若写，须限定为缺口图兼容性启发式规划）。

## 6. 与实验的对应关系

| 权利要求要素 | 实验锚点 |
|---|---|
| 证据缺口状态 + 粒度 | 模拟器 `supportable_granularity` / critical gaps |
| 公开意图节点 | `intended_cti_node_ids` + 信息边界测试 |
| 兼容性规划 | M2 为当前最佳实验实现；`project05_m3a_gap_compat` 仅为从属评分实施例 |
| 通道声明≠实现 | P0-#1 channel reliability |
| 停止/降级 | M4 STOP + should-stop 压力 |
| 三条异构实施例 | C07 THEIA + C08 ClearScope + C09 OpTC；均达标且无 ceiling violation |
| 成本效果边界 | 三条 holdout 上 M3a 均比 M2 更贵，不得写“降低平均取证成本” |
| 紧预算效果边界 | 135 个配对条件中 M3a 对 M2 无净胜，不得把 M3a 写成优越性或必要技术效果 |
