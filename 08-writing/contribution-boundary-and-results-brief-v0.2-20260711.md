# Project05 贡献边界与结果简报 v0.2

日期：2026-07-11

状态：Reviewer major revision 后冻结；替代 v0.1

## 1. 一句话定位

> Project05 不是新的攻击者分类器，也不以某个复杂规划器胜出为贡献；它把部分 CTI—本地证据对齐转化为受信息边界、预算、通道反馈和结论粒度约束的调查控制问题，并用同接口正负结果界定当前可部署策略及其失效边界。

## 2. 当前技术主线

```text
部分对齐与可回指 evidence claims
  -> 证据缺口状态
  -> 公开意图/通道/成本下选择采集动作或 STOP
  -> 执行器读取隐藏恢复集合并返回真实反馈
  -> 更新缺口、预算和可支撑结论粒度
  -> 达标、预算不足或不可达时停止/降级
```

不可删除的接口约束：

1. `intended_cti_node_ids` 与隐藏 `recoverable_claim_ids` 分离；规划器不得读取实际恢复集合。
2. 通道执行失败和零收益必须反馈到状态，而非在离线结果中被隐去。
3. 输出不得超过 `support_ceiling` 与当前内部可支撑粒度。
4. STOP 是正式动作；过早停止、正当降级和达标停止必须区分。

## 3. 方法角色冻结

| 方法 | 当前角色 | 可否写成主创新 |
|---|---|---|
| M2 | 透明部署策略/经验锚点 | 可写其审计性和当前折中，不可写全局最优 |
| M3a | action-gap 兼容性机制消融 | 否；C10 反例且聚合成本未胜 |
| Logistic/XGBoost | 监督动作价值对照 | 否；XGBoost 优于 Logistic 的部分指标，但未超过 M2 |
| AFA-VOI Myopic/Rollout-H3 | 通用 AFA 思想的同接口领域适配 | 否；不是 NOCTA/WinRegRL 官方复现 |
| Depth-2 Public | 冻结的有限前瞻候选 | 否；真实接入未过升级门槛 |
| DP Oracle | 受控非短视规划上界 | 否；读取完整转移概率，不可部署 |
| DQN/Dueling DQN | 关闭的工程支线 | 否；Gate B 未通过 |
| LLM | 待验证的离线语义编译/解释接口 | 否；主实验未调用 LLM |

## 4. 可以引用的核心结果

### 4.1 四个参数锁定真实案例

| Planner | Success | Mean cost | Regret | Zero-yield | Premature STOP |
|---|---:|---:|---:|---:|---:|
| Oracle | 1.0000 | 3.9333 | 0.0000 | 0.0000 | 0.0000 |
| **M2** | **1.0000** | **4.5333** | **0.6000** | 0.2667 | 0.0000 |
| XGBoost | **1.0000** | 4.8278 | 0.8944 | **0.2000** | 0.0000 |
| Logistic | 0.9833 | 5.0056 | 1.0565 | 0.3000 | 0.0167 |
| M3a | 0.9500 | 4.8421 | 1.0702 | 0.6111 | 0.0500 |

这里的 180 条件是四个攻击案例的重复遮蔽/通道条件，不是 180 个独立攻击。

### 4.2 通用 AFA 同接口适配

- Myopic 与 Rollout-H3 均为 180/180 内部达标，平均成功成本 4.9722。
- 二者相对 M2 的配对成本为 24 胜、91 平、65 负，聚合成本高 0.4389。
- 只能主张“本文实现的公开代理 AFA 适配未超过 M2”；不能主张 NOCTA、WinRegRL 或 AFA 方法族无效。

### 4.3 非短视边界

- 受控 192 环境中 Gate A 通过，说明可构造单步最优不等于长期最优的先决依赖结构。
- DP 计算复杂度未过 Gate B，当前没有启动 DQN 的必要。
- C07-C10 的公开 Depth-2 与 M2 均 180/180 达标，但成本 4.5556 高于 4.5333，未通过冻结升级门槛。

### 4.4 敏感性与代理效度

- 16 个 M2 单权重 ±25% 变体均保持 success=1.0000；13 个与原始 M2 完全同序，另 3 个平均成本增加 0.0222。该结果支持局部稳定，不证明全局最优。
- 三档 G 阈值未改变 C07-C10 结果，因为关键节点全覆盖条件主导。
- C07-C10 每节点仅一条 required claim，OR 与 AND 按定义相同；该比较不可识别，不能写成真实案例鲁棒性。
- C01-C06 多 claim 开发压力中，AND 使 M2 success 从 0.8000 降至 0.4963，说明内部 success 依赖证据组合语义，必须做人工校准。

## 5. 可以主张

1. 部分对齐可以被实例化为可更新的调查控制状态，而不是静态缺失列表。
2. 公开意图若由隐藏恢复内容反向生成，会泄漏节点级可恢复性；编译期校验和执行期通道隔离共同形成可审计信息边界。
3. 同一接口可比较规则、学习、AFA、有限前瞻和 Oracle，并保留失败策略的可证伪结果。
4. 在当前四案例和所评估的非 Oracle 策略内，透明 M2 提供最佳成本—达标折中和更清楚的审计路径。
5. 复杂方法未胜和 OR/AND 敏感性共同说明，下一瓶颈是状态/转移可识别性及人工效度，不是继续堆模型。

## 6. 不可以主张

1. 本文提高了 actor/campaign 归因准确率，或已经完成真实 APT 归因。
2. M2 全局最优、跨组织泛化，或简单规则普遍优于机器学习/AFA。
3. 本文正式复现 NOCTA、WinRegRL，或其原方法被证伪。
4. 真实攻击已证明非短视规划有收益，或 DQN 必要。
5. G0-G3 等价于分析师可支撑判断；当前双人盲标仍为空。
6. LLM 对规划性能有贡献；当前没有在线 LLM 因果实验。
7. 四个案例的 180 个重复条件是独立攻击样本。

## 7. 下一优先级

1. 完成双人盲标和一致性/校准，不允许用模型标签代替人工标签。
2. 在论文中维持“调查控制服务于归因”的题目与表述，不改回“新 APT 归因方法”。
3. 争取第三数据家族或更多独立 engagement，并增加多 claim corroboration。
4. 视目标 venue 决定是否补官方 AFA 实现；在此之前保持“domain adapter”边界。
5. 专利继续保护闭环与信息隔离，不把任何当前失败/未验证模型写入独立权利要求。
