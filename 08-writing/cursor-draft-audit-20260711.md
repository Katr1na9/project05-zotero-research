## 1. 必须纠正的事实性问题

1. **实验范围过时。** 草稿只覆盖 C07-C09，没有纳入 C10 OpTC Day 3 的参数锁定测试。
2. **M3a 的留出表现被写强。** C10 中 M3a 为 `36/45`，成功率 `0.8000`，过早停止率 `0.2000`；不能再写成“全部真实留出均 45/45 达标”。
3. **学习基线结果过时。** XGBoost v0.2 已扩展到 C07-C10：XGBoost 与 M2 均保持 `1.0000` 序贯成功率，但 XGBoost 平均成功成本 `4.8278`，仍高于 M2 的 `4.5333`。
4. **DQN 状态过时。** 非短视两级 Gate 已完成。Gate A 通过，证明存在稳定的“局部最优不等于长期最优”；Gate B 不通过，因为当前规模下完整 DP 仍可接受。因此结论不是“等待 DQN”，而是“采用轻量非短视规划，不启动 DQN 主模型”。
5. **独立性表述需收紧。** C07-C10 是四个参数锁定案例，但不是四个独立数据源家族：C07/C08 同属 DARPA TC E5，C09/C10 同属 OpTC，C10 只增强跨日同语料稳健性。

## 2. 需要收紧的科学主张

- 不能主张“新规划器全面优于基线”。当前最稳健的部署锚点仍是 M2。
- 不能主张“XGBoost 已证明泛化”。独立测试案例只有四个，重复 mask、intensity 和 seed 不是独立攻击样本。
- 不能主张“DQN 无效”。实验只说明当前规模下没有启动 DQN 的必要证据。
- 不能主张“LLM 是在线决策核心”。已完成实验中的在线规划器是规则模型、Logistic 和 XGBoost；LLM 目前仅是待独立验证的离线 schema 编译与解释接口。
- 不能主张“M3a 降低平均取证成本”。C07-C10 与紧预算曲线均不支持该结论。
