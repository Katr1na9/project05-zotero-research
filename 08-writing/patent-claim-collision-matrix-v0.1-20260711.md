## 2. 组合链判断

当前仍可能保留辨识度的链条是：

```text
部分对齐结果
  -> 可更新证据缺口状态
  -> 公开动作意图、通道和成本
  -> 不读取隐藏恢复集合的预算内动作/STOP 选择
  -> 通道执行后才用实际结果更新状态
  -> 输出下一控制动作或支持粒度受限的停止/降级结果
```

现有本地扫描尚未发现一项中文专利完整覆盖上述五步组合，但这不等于已证明新颖性。FTR-001、FTR-003、FTR-004、FTR-005 单独看都较宽，组合的主要区分点集中在 FTR-002 的信息边界及其与 APT 对齐缺口状态的协同。

## 3. 实验对权利要求的约束

- M3a 在紧预算条件下不优于 M2，不能把特定 M3a 公式写成必要技术效果。
- 可以把“根据缺口兼容性、成本和反馈选择动作”写成功能性组合步骤，把具体 M2/M3a 公式放入实施例或从属方案。
- 所有方法 ceiling violation 为 0，可用于说明支持粒度约束的实现结果，但独立攻击案例只有 3 个，不宜写成普遍性能保证。
- LLM 尚未运行，FTR-006 仍是 `needs-confirmation`。

## 4. 专利 Gate

当前状态仍为**可继续准备交底，但不可认定 filing-ready**。正式提交前至少还缺：

1. 在 CNIPA/商业专利库中对 G06F/G06N/H04L 相关分类做“取证动作调度、证据采集规划、部分可观测调查、停止/降级控制”的组合检索。
2. 获取候选近似专利的权利要求原文并逐项 claim chart，而不是只比摘要。
3. 明确 FTR-002、状态结构和执行反馈链的发明人贡献、权属及首次公开时间。
4. 由中国专利专业人员审阅“隐藏实际恢复集合”“公开意图节点”和“支持粒度”的清楚性及可实施性。

## 5. 当前建议

专利主线可继续，但不应围绕“新规划器更准/更省成本”组织，而应围绕**在不暴露未来恢复答案的条件下，将部分对齐缺口转成可执行、可停止、粒度受控的证据采集闭环**组织。
