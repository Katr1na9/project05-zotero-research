## 一、权利要求书

### 1. 独立方法权利要求

1. 一种面向不完整安全证据的调查取证动作规划方法，其特征在于，由计算设备执行，包括：

获取攻击行为图以及与所述攻击行为图部分对齐的本地安全证据声明集合，所述攻击行为图包括行为节点和行为节点之间的关联边，所述本地安全证据声明包括能够回指至原始安全事件的来源标识；

根据所述本地安全证据声明与所述行为节点之间的关联关系，确定已覆盖行为节点、未匹配行为节点和未匹配关键行为节点，并构建证据缺口状态，所述证据缺口状态至少包括当前可支撑调查结论粒度、剩余取证预算以及已执行取证动作的反馈信息；

获取候选取证动作集合以及供动作规划过程读取的公开动作视图，其中，各候选取证动作包括预执行公开目标、采集通道标识和动作成本，所述预执行公开目标在候选取证动作执行前根据动作模板、采集通道能力和调查请求中的至少一项生成或登记，所述公开动作视图不包括候选取证动作执行后实际恢复的安全证据集合；

在不读取所述实际恢复的安全证据集合的情况下，根据所述证据缺口状态、所述公开动作视图、所述动作成本和所述剩余取证预算，从所述候选取证动作集合中确定目标取证动作或停止动作；

在确定所述目标取证动作的情况下，输出与所述目标取证动作对应的采集控制指令，根据所述采集通道的执行结果获得新增安全证据声明或无新增证据反馈，并更新所述证据缺口状态和所述当前可支撑调查结论粒度；以及

重复确定目标取证动作和更新证据缺口状态，直至满足以下至少一项：所述当前可支撑调查结论粒度达到目标调查结论粒度、所述剩余取证预算不满足继续采集条件、所述目标调查结论粒度被确定为不可达、或者确定所述停止动作；并输出不高于所述当前可支撑调查结论粒度的调查结论或降级结果。

### 2. 从属方法权利要求

2. 根据权利要求1所述的方法，其特征在于，针对任一行为节点，将与该行为节点关联的必需安全证据声明按来源组进行划分，并为所述行为节点设置来源支持阈值 k；当当前可见安全证据声明覆盖的独立来源组数量不小于所述来源支持阈值 k 时，将该行为节点确定为已覆盖行为节点，其中，k=1 对应任一来源支持的覆盖方式，k=n 对应 n 个所需来源组均支持的覆盖方式，且所述来源支持阈值在动作执行前由版本化配置固定。

3. 根据权利要求1所述的方法，其特征在于，所述当前可支撑调查结论粒度根据节点覆盖率、关联边覆盖率、攻击阶段覆盖数量和关键行为节点覆盖状态中的至少两项确定，并由案例级证据支持上限进行截断，以使输出的调查结论不超过所述证据支持上限。

4. 根据权利要求1所述的方法，其特征在于，在候选取证动作进入动作规划过程之前，对规划过程可读取的配置字段、证据缺口状态字段和公开动作视图字段执行递归允许列表校验，并禁止所述动作规划过程读取实际可恢复声明标识、遮蔽成员信息、执行前的实际通道状态、随机参数、目标案例结果标签和最优动作路径中的至少一项；所述动作规划过程输出动作标识后，执行过程才读取与所述动作标识对应的完整动作对象。

5. 根据权利要求1所述的方法，其特征在于，所述动作成本由成本 profile 提供，所述成本 profile 包括 profile 标识、语义版本、冻结状态、动作覆盖清单和内容摘要值；在所述成本 profile 未冻结、动作覆盖不完整、内容摘要值不匹配或目标结果目录包含既有正式结果时，拒绝启动正式动作规划运行。

6. 根据权利要求5所述的方法，其特征在于，所述成本 profile 采用以下至少一种成本生成方式：各非停止动作采用统一单位成本；保留版本化历史相对成本；依据采集努力、证据易失性、数据规模、访问或合规开销以及系统侵入风险中的至少两项合成分级成本；或者依据动作级运营测量记录归一化生成连续成本；其中，缺失的评分或运营测量保持为未定状态，不使用动作规划结果或动作实际恢复集合进行回填。

7. 根据权利要求1所述的方法，其特征在于，候选取证动作的预期效果或采集通道可靠性由版本化先验 profile 提供，所述先验 profile 记录先验来源和缩放参数；调整供动作规划过程读取的通道可靠性先验时，保持执行过程用于产生实际通道结果的执行可靠性配置不变。

8. 根据权利要求1所述的方法，其特征在于，所述本地安全证据声明的接入包括：校验报告或事件集合的来源元数据；校验来源指针所指向的原始记录是否存在且与声明类型一致；区分原始事件观测和由安全产品生成的关联投影、自动标签或处置状态；以及在来源实体、时间或行为标识冲突时记录冲突并阻止未经核验的因果拼接。

9. 根据权利要求1所述的方法，其特征在于，所述采集通道包括主机溯源通道、主机日志通道、网络遥测通道、文件取证通道和内存取证通道中的至少一种；在采集通道不可用或未获得新增安全证据声明时，将动作标识、采集通道、预执行公开目标和无新增证据结果写入所述反馈信息，以调整后续候选取证动作的评价值或切换采集通道。

10. 根据权利要求1所述的方法，其特征在于，确定所述停止动作包括以下至少一种情形：当前可支撑调查结论粒度已达到目标调查结论粒度；剩余取证预算小于全部可执行非停止动作的动作成本；根据当前可执行动作和采集通道状态确定目标调查结论粒度不可达；或者全部可执行非停止动作的继续价值均不高于停止动作的终端价值；其中，在目标调查结论粒度不可达时输出当前可支撑调查结论粒度及至少一个未匹配关键行为节点作为降级原因。

11. 根据权利要求1所述的方法，其特征在于，当候选取证动作之间具有先决条件或解锁关系时，建立以证据缺口状态为状态节点、以候选取证动作为转移边的有限状态搜索空间，并根据至少两步的累计目标达成概率、累计动作成本或二者的组合确定所述目标取证动作。

## 二、说明书

### 1. 技术领域

本发明涉及网络安全、计算机取证和安全数据处理技术领域，尤其涉及一种在安全证据不完整、证据采集通道可能失效且取证预算受限的条件下，根据攻击行为图与本地安全证据的部分对齐结果规划后续取证动作，并对动作规划信息边界、动作成本版本和调查结论支持上限进行控制的方法。

### 2. 背景技术

在网络攻击调查中，威胁情报报告、攻击知识图谱或攻击行为模板通常描述多个攻击阶段及其关系。本地环境能够获取的主机日志、网络流量、进程事件、文件事件、注册表事件或溯源图记录可能只覆盖其中一部分。日志保留周期不足、采集代理未部署、取证窗口不完整、权限受限、跨组织访问以及来源标识不一致，均会造成证据缺失。

现有方案可以从威胁情报文本抽取攻击行为、构建或压缩攻击图、将行为与审计记录对齐，或者基于已有特征输出分类结果。这些方案在完成部分对齐后通常输出匹配项、异常实体、候选标签或缺失项，但未必能够自动确定下一项证据采集操作。主动特征获取、代价敏感观测和基于马尔可夫决策过程的取证动作选择能够在有限预算内选择后续观测；上述一般方法本身不作为本发明的发明点。

在安全证据采集场景中，一个动作可能因采集通道失效而无产出，也可能一次返回多条来源不同的记录。若动作规划过程能够读取动作实际恢复的证据、执行前的真实通道状态、遮蔽配置或结果标签，则离线规划效果可能无法在部署条件下复现。另一方面，若动作成本、证据覆盖语义或通道先验没有版本和来源记录，同一运行的成本排序和停止路径可能随人工修改而改变，难以审计。

此外，安全产品生成的事件关联边、ATT&CK 标签和处置状态属于派生上下文时，不能自动替代能够回指原始事件的事实声明。当前证据不足或目标不可达时，持续采集会造成无新增证据的资源消耗，直接输出高粒度结论又可能超过当前材料的支持能力。因此，需要一种将部分对齐转换为机器可执行证据缺口状态、隔离规划与执行信息、版本化管理关键参数、接收执行反馈并限制输出粒度的方法。

### 3. 发明内容

#### 3.1 要解决的技术问题

本发明至少解决以下技术问题：

1. 部分对齐结果难以直接转换为下一项证据采集控制指令；
2. 规划阶段与执行结果之间缺少机器可校验的信息边界；
3. 证据组合规则、动作成本和通道先验缺少版本化及冻结校验，导致运行难以复核；
4. 采集通道失败或动作零收益时缺少统一反馈和回退机制；
5. 当前证据不足时缺少对调查结论粒度和停止原因的机器可执行约束。

#### 3.2 技术方案

本发明以攻击行为图和可回指原始安全事件的本地安全证据声明为输入，计算节点覆盖、边覆盖、关键缺口、阶段覆盖和当前可支撑调查结论粒度，形成证据缺口状态。节点覆盖可以采用版本化 k-of-n 来源支持规则，既允许单一来源支持，也允许要求多个独立来源共同支持。

候选取证动作具有在执行前产生的公开目标、采集通道和动作成本。动作规划过程只接收允许列表内的公开配置、状态和动作字段；实际恢复集合、遮蔽信息、执行前真实通道结果和目标标签不进入规划视图。动作规划过程输出动作标识后，执行过程才读取完整动作对象、调用采集通道并返回新增证据或无新增证据反馈。

动作成本、corroboration 规则和规划先验分别由版本化 profile 提供。正式运行前校验 profile 标识、版本、冻结状态、动作覆盖和摘要值。对于基于人工评分或运营测量的成本 profile，缺失值保持未定；未冻结草案不得进入正式运行。规划先验的敏感性运行只改变规划器信念，保持执行可靠性不变。

执行结果被编译为带来源指针的安全证据声明，合并到当前可见集合并重新计算证据缺口状态。该过程持续至达到目标粒度、预算不足、目标不可达或选择停止。停止时输出当前支持粒度、已覆盖和未覆盖关键节点、预算状态以及停止或降级原因。

#### 3.3 有益效果

与仅输出匹配结果或缺失列表的处理方式相比，本发明至少具有以下技术效果：

1. 将部分对齐结果转换为可更新的机器状态，使计算设备能够输出具体采集控制指令；
2. 通过字段允许列表和先规划后执行的对象读取顺序，降低规划过程提前读取执行结果的风险；
3. 通过 profile 标识、版本、冻结状态和内容摘要值，使影响动作选择的成本、证据组合规则和先验能够被复核；
4. 通过采集通道反馈和显式停止动作，区分目标达成、预算不足、通道失败、零收益和结构不可达；
5. 通过来源支持阈值和证据支持上限，约束处理过程不输出超过当前证据支持能力的调查结论；
6. 在具有先决关系的动作空间中，可通过有限深度搜索或动态规划评价多步累计结果。

上述效果是方法结构产生的可执行性和可审计性效果。本说明书不主张任一具体规划器在所有场景中必然降低平均取证成本，不主张人工标注一致性已经完成，不主张运营实测成本已经取得，也不把内部目标达成率等同于攻击者识别准确率。

### 5. 具体实施方式

#### 5.1 数据对象与来源角色

攻击行为图可由威胁情报报告、攻击知识库、规则编译器或人工分析结果产生。行为节点记录节点标识、阶段、关键性和证据关联规则；关联边可表示先后、因果、数据流、控制流或阶段依赖。

安全证据声明是原始安全事件的规范化表示，可包括声明标识、声明类型、主体、客体、动作、时间、来源通道和来源指针。来源指针可以是事件 UUID、日志行号、文件偏移、遥测主键或原始文件哈希与记录序号的组合。

来源角色至少区分原始事件观测与派生上下文投影。安全产品生成的事件关联边、自动技术标签、处置状态或聚合关系可作为上下文保留；在未回指并核验原始事件前，不自动作为独立事实声明或攻击者实体真值。不同来源的实体、时间或行为标识不一致时，系统保留冲突标志并阻止未经核验的因果拼接。

#### 5.2 证据缺口状态与 k-of-n 覆盖

状态构建过程计算已覆盖节点、未覆盖节点、关键缺口、已覆盖边、阶段覆盖、证据类型覆盖、预算和动作反馈。对每个节点，将 required claims 依据来源标识或来源组规则划分，并读取冻结 corroboration profile 中的阈值 $k$。当可见独立来源组数量达到 $k$ 时节点被覆盖。

当 $k=1$ 时，任一所需来源即足以覆盖，适用于探索性或低风险筛查；当 $k=n$ 时，全部 $n$ 个所需来源组均需可见，可作为对抗误导或高粒度输出的保守实施方式；还可以设置 $1<k<n$。所述规则须在案例运行前固定并记录 profile 摘要，不能在查看规划结果后反向选择。

可支撑调查结论粒度可以被离散为未知级、行为或技术级、阶段或意图级以及活动或 campaign 级。其阈值可以根据节点覆盖、边覆盖、阶段数和关键节点覆盖配置，并由 `support_ceiling` 截断。具体阈值仅为实施例，不限定保护范围，也不自动代表人工结论或攻击者识别正确性。

#### 5.3 预执行目标与运行时信息边界

预执行公开目标在动作执行前由版本化动作模板、采集通道能力、调查请求或受结构约束的生成过程产生。生成过程不得读取该动作在当前案例中实际可恢复的声明集合。动作编译阶段可以比较公开目标与实际恢复集合覆盖的节点；若二者完全相同，则将其标记为高风险审计项并检查生成来源，但不因集合偶然相同而自动认定泄漏。

运行时对配置、状态和动作分别维护字段允许列表，并递归拒绝隐藏恢复标识、required claim 标识、遮蔽成员、随机 seed、执行前实际通道状态、Oracle 路径和目标标签。可选的模型特征也必须由允许列表内字段派生。规划器返回动作标识后，执行器再从受限存储读取完整动作对象。通过对隐藏结果进行置换并验证规划输出不变，可以测试选择器是否依赖被禁止字段。

#### 5.4 成本 profile 与正式运行 Gate

成本 profile 为每个候选动作提供成本值，并至少记录 profile ID、语义版本、状态、动作清单和 SHA-256。正式运行要求 profile 状态为 frozen、动作集合与案例动作精确对应、数值满足 schema 且摘要匹配；草案、缺动作、额外动作或摘要不一致时拒绝运行。为了避免覆盖已有证据，输出目录必须为空。

第一种 profile 保留历史相对成本，用于复现冻结结果。第二种 profile 将全部非停止动作设为单位成本，用于比较动作步数。第三种 profile 把成本分解为采集努力、易失性、数据量、访问或合规开销和侵入风险，并在独立评分和冻结后合成。第四种 profile 使用动作级扫描字节、分析师时间、机器时间、保留窗口、涉及主机数或授权步骤等运营记录归一化生成连续成本。

第三种和第四种 profile 在评分或测量缺失时保持 draft 和 `formal_ready=false`，不得以旧成本、动作类型均值、实际恢复数量或规划器结果回填。各 profile 产生的结果分目录保存，不能用某个规划器受益后的结果反向修改 profile。

#### 5.5 动作评价和先验分离

动作评价可以根据预期支持粒度增量、预期不确定性降低、预期过度推断风险降低、阶段缺口、证据类型缺口、历史零收益和成本中的至少两项计算。一个可选实施方式将评价表示为信息价值项减去成本换算系数与动作成本的乘积。所述换算系数由版本化配置提供，其具体数值不是独立权利要求的必要限制。

另一可选实施方式根据预执行公开目标与当前缺口的交集、关键缺口命中数、一般缺口命中数、公开目标相对缺口的精确率和召回率及成本计算评价值。还可以使用线性模型、树模型或有限深度搜索，但模型类型不是本发明必要特征。

采集通道可靠性包括规划器信念和执行器实际可靠性两个对象。进行先验变化时，只替换规划器读取的先验 profile，并保持执行器可靠性、随机条件和案例输入不变，以区分“规划信念变化”与“环境本身变差”。

#### 5.6 通道执行、反馈与状态更新

目标动作被转换为采集控制指令，例如扩展日志时间窗、查询主机溯源子图、读取网络会话、采集文件元数据或执行内存取证。通道执行过程返回原始记录、失败状态或空结果。证据接入过程将有效记录编译为新声明并保留来源指针。

若没有新增证据，系统记录动作、通道、公开目标和零收益结果，后续可以降低同类动作评价或切换通道。若获得新证据，系统合并声明、重新计算 coverage 和支持粒度，并扣减 profile 给出的成本。规划器在下一步只读取更新后的公开反馈，不读取未实现的未来通道结果。

#### 5.7 停止与降级

STOP 是候选动作集合中的零成本动作。目标已达到、预算不足、结构不可达或全部继续动作的价值不高于 STOP 时，系统停止。输出至少包含当前支持粒度、已覆盖关键节点、未覆盖关键节点、预算状态和停止原因。

当证据只支持行为或技术级而不支持活动级时，系统输出较低粒度结果并保留缺口，不推断未被支持的高粒度实体。测试阶段可以使用完整信息可达性上界识别过早停止，但该上界不进入部署规划器公开视图。

#### 5.8 多步规划实施例

当动作之间具有 prerequisite 或 unlock 关系时，单步高收益动作可能成为诱饵。系统可把离散证据缺口状态作为节点、候选动作作为转移边，执行深度不小于2的搜索、束搜索或动态规划，并以累计目标达成概率和累计成本评价路径。

在一个受控验证中，192 个独立参数环境包含不同解锁深度、预算、诱饵数量和链路可靠性；完整动态规划优于一步策略，说明多步依赖在构造环境中可以存在。该实施例不用于主张真实攻击中多步依赖的发生率，也不要求采用 DQN。

#### 5.9 分层安全事件实施例

在四个参数锁定攻击链中，系统以活动或 campaign 级为支持上限，在 180 个案例内重复条件上验证采集闭环。在一个公开 Windows 攻击仿真链中，冻结锚点缺失，系统将支持上限由活动级降至阶段或意图级；该案例的冻结主分析要求多条 provider claims 共同支持，平均历史相对成本为 3.6667，将覆盖方式改为任一 claim 即可支持时成本为 1.0222。该差异说明证据组合规则会改变动作路径和成本，不能被解释为规划器本身改进。

在一个生产 SOC 衍生 incident 中，元数据 Gate 从 13119 条候选记录保留 5 条，事件来源 Gate 再保留 2 条，其中选定案例包含 117 条网络安全设备事件和 2 条 Windows 目录服务线索。厂商关联图只作上下文，支持上限固定为行为或技术级。该案例用于说明来源核验、投影隔离和自然降级可实施，不用于证明攻击者识别正确性。

在六个独立案例、每个案例 45 个遮蔽和随机条件的正式运行中，历史相对成本与统一单位成本均能驱动闭环，但不同规划器的成本排序发生变化。所述 270 个条件属于六个案例内的重复测量，不是 270 个独立攻击；统一单位成本表示动作步数，也不代表真实运营成本。本实施例因此不支持任一具体规划器在所有场景中普遍降低成本。

#### 5.10 外部真值、人工构念和可选语义编译

安全证据声明可以由规则解析器、人工录入或受结构约束的语义模型生成，但均需通过 schema、来源指针和不受支持声明校验。独立权利要求不限定使用大语言模型，也不把生成模型输出直接作为最终调查结论。

本方法的可执行不以双人标注一致性通过为必要条件：公开目标、节点关联和支持上限可以由版本化模板和结构规则产生并由人工复核。当前人工一致性结果和外部 actor ground truth 的完成状态不构成本发明技术效果。若后续引入分析师效用或实体正确性，它们属于评价端点，不改变权利要求1的信息隔离、执行反馈和支持限制闭环。

## 三、说明书摘要

本发明公开一种面向不完整安全证据的调查取证动作规划方法。该方法获取攻击行为图及与其部分对齐、能够回指原始安全事件的安全证据声明，构建包括未匹配关键行为节点、当前可支撑调查结论粒度、剩余预算和动作反馈的证据缺口状态；获取具有预执行公开目标、采集通道和动作成本的候选取证动作，并通过公开动作视图隔离动作执行后实际恢复的安全证据；在不读取实际恢复证据的情况下确定目标取证动作或停止动作；执行目标取证动作后，根据新增证据或无新增证据反馈更新证据缺口状态；重复上述过程并输出不高于当前可支撑粒度的调查结论或降级结果。可选地，所述方法使用版本化 k-of-n 来源支持规则、成本 profile 和运行时字段允许列表。本发明将部分对齐结果转换为可审计的证据采集控制闭环，并约束规划阶段的信息泄漏和证据不足时的越级输出。
