## 3. 论文叙事

### 推荐题目

面向不完整证据 APT 归因的对齐感知证据缺口建模与成本约束主动取证规划

### 核心科学问题

在动作真实恢复结果对规划器不可见、通道可能失效且预算有限时，如何利用当前 CTI 缺口与公开动作意图选择下一证据获取动作，并避免在证据不足时越级归因？

### 可写贡献

1. 定义对齐之后的证据缺口状态和粒度受控主动取证任务，把对齐结果从终点变为规划状态。
2. 建立 `intended ≠ OR(recoverable)` 信息边界与通道门控，避免规划器读取答案键。
3. 提出节点级 action–gap 兼容性 M3a，并与成本、执行反馈和显式 STOP 组成闭环。
4. 在开发矩阵、M4 压力测试和三条异构真实 holdout 上给出可复现实验，同时公开成本优势未成立与部分可达选路失败。

### 必须如实写出的结果

- C07/C08/C09 上 M3a 与 M2 均为 `45/45` 成功，无 ceiling violation。
- M3a 成本均高于 M2；三源平均额外 regret 为 `0.5481`。
- 论文贡献是问题设定、信息边界、闭环机制和跨异构 trace 可复现，不是“新规划器全面打赢基线”。
- 部分可达紧预算下 M3a 失败，说明“会停止”不等于“会选路”。

### LLM 的准确位置

- 可做：把 CTI、IOC、日志和 provenance 输出编译成受 schema 约束的 evidence claims；草拟动作公开意图；生成带来源指针的缺口解释和最终报告。
- 当前未做：在线动作效用预测、自由 actor 归因、闭环自学习和成本优化。
- 写作规则：论文标题、摘要和主贡献不应把 LLM 放在中心；若保留 LLM，只能作为未单独评估的语义编译接口或后续实验模块。

## 4. 专利叙事

### 建议名称

一种基于对齐感知证据缺口状态的成本约束取证动作规划方法及系统

### 技术问题—手段—输出

- 技术问题：部分对齐和不可靠采集通道下，系统无法在不读取隐藏恢复结果的前提下选择下一取证动作，并容易在证据不足时继续消耗资源或越级输出归因。
- 协同技术手段：证据缺口状态、公开动作意图、通道标识与成本、action–gap 兼容性、执行后状态更新、粒度上限和 STOP/降级。
- 具体输出：候选取证动作控制指令，或带当前可支撑粒度的停止/降级结果。

### 独立权利要求应保留的必要链

1. 获取对齐结果并构造可更新证据缺口状态。
2. 获取具有公开意图目标、采集通道和成本的候选动作。
3. 在不读取隐藏实际恢复集合的条件下，根据缺口兼容性和预算选择动作或 STOP。
4. 执行动作并根据实际采集结果更新状态和可支撑粒度。
5. 达标、预算耗尽或不可达时输出粒度受控结果。

### 只适合从属权利要求/实施例的内容

- M3a 的具体评分项和权重结构。
- technique / tactic-intent / campaign 的具体粒度序列。
- network telemetry 与 host forensics 的可靠/不可靠回退。
- DARPA E3/E5、OpTC、具体 PID、IP、事件数量和实验指标。

### 暂不进入正式权利要求

- LLM 语义编译：目前只有问题定义和接口设想，缺独立准确率与一致性实验，状态为 `needs-confirmation`。
- 在线 LLM 效用预测、GNN/RL、自学习优越性：`unsupported`。
- “降低平均取证成本”或“M3a 优于 M2”：被三条 holdout 结果直接否定。
- 宽泛 CTI–provenance 对齐、多源融合和多轮调查循环。
