# CN117560223B：一种基于 IP 及威胁情报知识图谱的威胁归因预测方法

## 基本信息

- 类型：中文专利
- 专利号：CN117560223B
- 题名：一种基于 IP 及威胁情报知识图谱的威胁归因预测方法
- 来源：https://patents.google.com/patent/CN117560223B/zh
- 当前状态：纳入 Project05 二次深扫高风险材料。

## 它在做什么

该专利面向威胁归因预测，核心组合是：

```text
IP 信息
  + 威胁情报知识图谱
  + 机器学习/集成学习预测
  -> 威胁归因结果
```

公开信息显示，该专利已经把 IP 与威胁情报知识图谱结合，用于威胁归因预测。

## 对 Project05 的撞题影响

该专利直接堵住：

1. “IP + 威胁情报 KG 做归因预测”。
2. “知识图谱辅助威胁归因预测”。
3. “基于威胁情报实体关联关系的威胁行为体预测”。

Project05 后续如果使用 IOC/IP/基础设施证据，不能把“IP 关系图或威胁情报知识图谱预测 actor”作为核心创新。

## 与 Project05 当前方向的区别

Project05 当前可保留的区别是：

- IP/KG 只是证据来源之一；
- 系统重点不是预测 actor，而是判断当前证据是否足以支持 actor 归因；
- 当 IP/KG 证据不足、冲突或容易共享时，系统应降级到 campaign/intent/technique 或拒答；
- LLM 只解释证据账本和门控结果，不负责凭 IP/KG 自由裁决 actor。

## 风险等级

红色。

这进一步说明“威胁情报 KG + 归因预测”已经不能作为 Project05 的主创新。
