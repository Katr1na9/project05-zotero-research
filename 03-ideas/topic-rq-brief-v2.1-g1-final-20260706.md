# Project05 研究问题卡 v2.1 - G1 Final

日期：2026-07-06  
状态：Stage 1 / RQ Scoping 通过版  
主线：对齐感知证据状态建模 + 面向归因粒度提升的主动取证规划

## 1. 最终主 RQ

在证据不完整的 APT 归因场景中，如何将 CTI 侧攻击行为图与本地观测证据之间的对齐状态建模为可更新的证据状态，并在成本约束下估计候选取证动作对归因粒度提升的期望价值，从而规划取证动作序列，使系统以尽可能低的取证成本达到当前证据可支撑的最高归因粒度？

一句话版本：

> 当 CTI 中描述的攻击行为只在本地证据中被部分观测到时，系统不直接猜 actor，而是判断当前最多能归因到哪一层，并决定下一步补哪类证据最值得。

## 2. 研究对象

Project05 研究的不是一个新的 APT actor 分类器，也不是一个新的 CTI-provenance 对齐算法，而是一个位于二者之后的决策过程：

```text
已有或复用的对齐器输出
  -> 对齐感知证据状态
  -> 当前可支撑归因粒度判断
  -> 候选取证动作价值估计
  -> 成本约束下的动作规划
  -> 再对齐与停止
```

因此，威胁狩猎图匹配工作中的匹配分数、匹配子图、缺失节点、冲突边、TTP 标签和攻击场景不是 Project05 的终点，而是 Project05 的输入状态。

## 3. 核心技术问题

### Q1：证据状态如何表示？

需要把对齐结果从“匹配成功/失败”扩展为结构化状态，包括：

- CTI 行为节点的覆盖率；
- 本地观测节点和边的匹配置信；
- 未匹配的 CTI 行为片段；
- 本地证据中的冲突或反证；
- 候选 actor/campaign 假设之间的区分度；
- 当前能够支撑的最高归因粒度。

### Q2：归因粒度如何定义？

建议采用从低到高的粒度格：

```text
unknown / no attribution
  -> technique-level
  -> intent / tactic-level
  -> campaign-level
  -> actor-family / actor-cluster-level
  -> named actor-level
```

这里的核心不是强行输出最高层级，而是选择“当前证据能承担责任的最高层级”。

### Q3：取证动作如何定义？

候选动作不应写成泛化的“向 LLM 追问更多信息”，而应是安全调查中的证据获取操作，例如：

- 扩展日志时间窗口；
- 查询特定主机或进程的 provenance 子图；
- 拉取网络流量会话摘要；
- 扩展 IOC 富集；
- 获取样本静态/动态分析结果；
- 查询基础设施历史关系；
- 请求某类 ATT&CK technique 的局部证据。

每个动作应有成本、可返回证据类型和可能提升的归因粒度。

### Q4：动作价值如何估计？

动作价值不是“置信度是否增加”这么宽泛，而是：

> 该动作在给定当前证据状态下，对提升可支撑归因粒度、降低过度归因风险、区分候选假设的期望收益。

可以从简单到复杂设计三层：

1. 规则/启发式价值函数；
2. AFA 风格的短视信息增益或条件互信息；
3. 非短视规划或近似 POMDP 策略。

## 4. LLM 的位置

LLM 不作为自由归因裁判。它在 Project05 中承担四个受控角色：

1. **证据语义编译**：把 CTI 文本、日志摘要、IOC、样本描述翻译成规范化 evidence claims。
2. **对齐缺口解释**：说明哪些 CTI 行为没有本地证据支持，哪些本地证据与候选假设冲突。
3. **取证动作自然语言化**：把规划器选出的动作解释成分析师能理解的调查请求。
4. **最终受控解释**：基于证据状态和粒度门控结果生成可审计说明。

禁止让 LLM 直接执行：

- 自由选择 actor；
- 自由决定“再找什么证据”；
- 以自然语言置信度替代形式化动作价值；
- 在没有证据回指时生成归因结论。

## 6. 可检验假设

### H1：对齐感知状态优于普通证据计数

如果将 CTI-local alignment 的覆盖、缺口、冲突和候选假设区分度显式编码为状态，那么系统在证据缺失场景下的归因粒度选择准确率应高于只统计证据数量或匹配分数的 baseline。

可观察预测：

- over-attribution rate 下降；
- correct abstention / downgrade rate 上升；
- granularity selection accuracy 上升。

### H2：主动取证优于固定顺序或随机补证

如果候选取证动作按归因粒度收益和成本建模，那么在相同预算下，主动规划策略应比随机、固定顺序、全量取证前缀策略更快达到目标粒度。

可观察预测：

- 达到目标粒度的平均成本更低；
- 达到目标粒度的平均步数更少；
- next-best-evidence 排序更接近 oracle。

### H3：LLM 受控参与优于 LLM 直接归因

如果 LLM 被限制在证据编译、缺口解释和最终说明，而不是直接裁决 actor，那么它应减少幻觉式归因，并提高解释中的 evidence grounding correctness。

可观察预测：

- unsupported attribution claim 减少；
- 解释中的证据回指准确率提高；
- 长文本/缺失证据场景下稳定性提高。

## 7. 输入与输出定义

### 输入

- CTI 侧攻击行为图或行为序列；
- 本地观测证据图或证据集合；
- 初始对齐结果；
- 候选 actor/campaign 假设集合，可为空或开放集；
- 取证动作集合与成本表；
- 预算约束或停止阈值。

### 输出

- 当前证据状态；
- 当前可支撑的最高归因粒度；
- 每个候选取证动作的价值估计；
- 推荐取证动作序列；
- 终止时的粒度受控归因结论；
- LLM 生成的受控解释与证据回指。

## 8. 非目标

Project05 当前阶段不做：

- 新的 CTI-provenance 图对齐算法；
- 新的 TTP 抽取模型；
- 新的 actor 分类器；
- 通用安全调查 agent；
- 以 LLM 为核心的自由归因框架；
- 只输出缺失证据 list 的解释系统。

这些内容可以作为上游、baseline 或消融对象，但不能作为主创新。

## 9. G1 判定

G1 通过。

理由：

- 研究对象明确：对齐之后的证据状态与取证规划。
- 输入输出明确：证据状态、动作集合、成本、归因粒度、动作序列。
- 可评估：成本、步数、粒度准确率、过度归因率、拒答/降级正确率、证据回指正确率。
- 与红线有边界：不重复对齐算法、多源融合归因、LLM 归因框架和告警调查循环。

带条件通过项：

- G2 仍需补 TAA-EPLMR 复核、APTChaser/GAPT 正文获取和中文专利侧检索；CLIProv/APT-CGLP/APT-ATT 已于 2026-07-07 升级为全文精读，US12530469 权利要求原文已从当前 workflow 剔除，仅保留摘要级红线提醒。
