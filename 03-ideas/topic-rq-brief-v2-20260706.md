## 1. 主研究问题（RQ）

> 在证据不完整的 APT 归因场景中，如何以"CTI 侧攻击行为图与本地观测证据的对齐状态"为证据画像，估计各候选取证动作对**归因粒度可提升性**的期望增益，并在成本约束下规划取证动作序列，使系统通过"对齐—评估—补证—再对齐"闭环，以最小取证成本达到证据可支撑的最高归因粒度？

一句话通俗版：别人回答"报告里的攻击在我日志里有没有"，我们回答"匹配得不完整时，下一步补哪块证据最划算、补到什么程度才敢下多细的归因结论"。

## 2. 子研究问题

- **RQ1（证据状态表示）**：如何把对齐状态（匹配完整度、缺口类型、冲突证据、候选假设后验）编码为可供价值估计使用的状态表示？LLM 证据语义编译在何处发挥作用（把异构取证产出编译为可比较的证据主张）？
- **RQ2（证据价值估计）**：AFA 的短视 CMI 类目标如何推广到归因粒度格（technique/intent/campaign/actor/unknown）上的分层决策目标？非对称损失如何编码"过度归因代价 ≫ 降级输出代价"？
- **RQ3（规划与停止）**：成本约束下短视贪心 vs 非短视（Q^NA 子模近似 / EC² / MCTS）取证规划的适用边界？停止准则如何从"输出预测"推广为"选择输出粒度层级"（粒度门控即广义停止决策）？
- **RQ4（评测）**：如何在公开数据上构造证据消融（evidence ablation）基准，区分"系统性缺失"与"人为遮蔽"（von Kleist 式现实评估），并定义取证效率与归因可靠性的联合指标？

## 3. 输入 / 输出 / 场景 / 指标（G1 要件）

### 输入

- 一份 CTI 报告侧攻击行为图（复用 AttacKG+/EXTRACTOR 式抽取，或基准自带）；
- 初始本地观测证据（部分溯源子图 / 流量摘要 / IOC 命中，来自 DARPA TC、OpTC 等公开数据构造）;
- 取证动作空间及成本表（按证据类型分组：拉取日志窗口、查询基础设施历史、样本特征分析、扩展 IOC 富化等，动作揭示一组证据）；
- 预算约束（硬预算 B / 软成本权重 α）。

### 输出

- 取证动作序列（每步动作 + 决策依据）；
- 每步更新后的对齐状态与归因粒度评估；
- 终止时的粒度门控结论（最高可支撑层级 + 候选假设 + 证据回指）；
- LLM 受控解释（结论、不能更细的原因、已花成本）。

### 场景

证据不完整、证据冲突、共享 TTP、候选行为体不可区分、unknown actor——即"一次对齐解决不了问题、必须决定补什么"的真实调查处境。

### 指标

- 取证效率：达到目标粒度所需成本/步数（vs 随机、固定顺序、贪心启发、无规划全量取证）；
- 归因可靠性：over-attribution rate、correct abstention、granularity selection accuracy、open-set rejection；
- 价值估计质量：next-best-evidence 排序与 oracle 排序的一致性（NDCG 类）；
- 校准：ECE、Brier；解释质量：evidence grounding correctness。

| 已有线 | 它做到哪 | 我们不重复什么 | 我们的差异 |
