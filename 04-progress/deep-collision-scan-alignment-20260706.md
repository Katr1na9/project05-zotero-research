## 3. 该谱系的共同任务边界（Project05 的剩余空间）

上述所有工作的输出终点是：**匹配得分 / 告警 / 匹配子图 / TTP 标签 / 攻击场景**。经摘要级核查，它们均未做：

1. **归因层级语义**：匹配/对齐结果不向 campaign/actor 归因粒度推进，也不评估"当前对齐结果能支撑哪一级结论"；
2. **对齐质量感知的证据充分性**：不处理报告侧主张与本地观测之间的冲突、部分对齐、对齐失败的证据学含义；
3. **对齐缺口驱动的取证规划**（候选 B 的核心）：对齐不足时，没有任何工作输出"下一步应采集什么本地证据来提升对齐完整度/归因粒度"；
4. **闭环**：狩猎线全部是单向单轮（给定日志+报告→匹配结果），没有"对齐→评估→补证→再对齐"的迭代闭环，更没有在真实平台上执行取证动作的闭环演示。

## 4. 对主线的修正结论

1. **候选 A 的"对齐算法"定位作废**：不能再把"提出一种新的 CTI-溯源图对齐/匹配方法"作为主创新，POIROT→APT-CGLP 谱系 + CLIProv 已经把结构匹配、GNN 匹配、对比学习跨模态对齐全部占住。
2. **"日志→TTP 语义提升"单点也作废**：CLIProv 已输出 TTP 识别与攻击场景。
3. **A 与 B 必须融合成一个闭环才成立**：
   - 对齐模块降级为**复用上游**（可直接用 POIROT/MEGR-APT/CLIProv 式匹配器作为基座与 baseline）；
   - 主创新上移为：**以对齐状态为证据状态表示，建模各候选取证动作对"归因粒度可提升性"的期望增益，规划最优取证序列，并迭代重对齐**；
   - 狩猎线的"终点"（匹配结果）变成 Project05 的"起点"（证据状态），这是与整条谱系的本质区别；
   - 评测立足公开数据：DARPA TC / OpTC（狩猎线通用基准）+ 公开 CTI 报告构造 evidence ablation 场景，取证动作在数据集上以"揭示被遮蔽证据"的方式模拟执行。
   - （2026-07-06 用户决定：暂不引入 Project03/CENI 平台联动，Project05 独立成立；平台演示仅作为远期可选项，不进入论文与专利主线。）
4. **修正后的主线表述（v2）**：

   > 面向 APT 归因的对齐感知证据状态建模与主动取证规划：以 CTI-本地证据对齐状态为证据画像，评估当前可支撑的归因粒度，规划能最大化归因粒度增益的取证动作序列，形成"对齐—评估—补证—再对齐"闭环。

5. **与 US12530469 的区分要点**：该专利按摘要和说明书概要可识别为告警有效性调查循环（置信度阈值→追加数据请求），Project05 限定在归因粒度层级的证据价值估计模型 + 面向对齐缺口的取证动作排序，且动作空间是安全证据采集操作而非 LLM 追问。权利要求原文补读已从当前 workflow 剔除。

### 5.2 找到 B 模块的理论根基：Active Feature Acquisition（AFA，主动特征获取）

- ML 领域已有成熟研究线：AFA 综述（arXiv:2502.11067，2026-02 更新版）将其统一形式化为 POMDP（部分可观测马尔可夫决策过程），方法分类涵盖贪心条件互信息、模型基规划、RL 策略、非贪心（NOCTA arXiv:2507.12412、acquisition-conditioned oracle ICML 2024）。
- **安全侧应用排查结果**：仅存在"RL 顺序特征选择做恶意软件分类"先例（DQFSA、Dueling Double DQN 框架 ScienceDirect 2026、MPRLDroid），全部是扁平特征向量 + 单标签分类。
- **确认的空档**：AFA/POMDP 形式化用于"对齐状态证据 + 归因粒度分层目标 + 异构取证动作"未被占据。
- 对 B 的意义：
  1. 理论深度有依托（POMDP 实例化，可借用 AFA 全套方法与保证），洗掉"控制层/外挂"质疑；
  2. 相关工作必须引 AFA 线，并回答"为什么不是直接套 AFA"：证据非独立同分布、状态是结构化对齐图而非特征向量、目标是带拒答的层级决策而非扁平分类、动作有领域成本结构；
  3. DQFSA/DDQN 恶意软件先例列为橙色风险（任务不同，需引用区分）。
