# APT-ATT 未获取情况下的风险保留说明

日期：2026-07-06

## 1. 当前状态

APT-ATT 正文暂未获取，因此不能把它视为已完成精读文献。当前只能把它放入“高风险待复核文献”，在最终确定专利题目、权利要求和论文创新点之前继续寻找全文。

这不影响 Project05 继续推进，因为当前选题已经从宽泛的“多源证据融合 + LLM 辅助 APT 归因解释”收窄到更具体的问题：

> 面向证据不完整场景的 APT 归因可判定性评估、分层降级、拒答控制与缺失证据需求生成。

该问题的重点不是再做一个 actor 分类器，也不是再做一个 evidence path reasoning 框架，而是判断“当前证据是否足以支持某一层级的归因结论”。

## 2. 为什么不能等 APT-ATT 再推进

APT-ATT 可能覆盖的方向大概率包括：

- APT 归因任务；
- ATT&CK/TTP 特征；
- LLM 辅助分析；
- 证据链或攻击行为链；
- 攻击组织候选排序或解释。

这些方向与 Project05 原始宽题高度接近，但与当前收窄后的核心仍有可区分空间。当前可先推进“避让版”专利与实验设计，再在拿到 APT-ATT 正文后做二次碰撞审查。

## 3. 当前必须保留的红线

在 APT-ATT 未读到正文前，以下表述不能作为最终创新点：

1. “基于 LLM 的 APT 归因方法”。
2. “基于 ATT&CK/TTP 的攻击组织归因方法”。
3. “基于证据链/攻击路径的大模型归因解释方法”。
4. “基于多源证据融合的 APT 归因方法”。
5. “基于知识图谱/RAG 的威胁行为体归因方法”。

这些说法过宽，很容易与 TAA-EPLMR、LLMAPT、AURA、APT-MMF、APT-ATT 或中国专利发生撞题。

## 4. 当前可以推进的安全表述

可以继续推进的表述应强调“证据不完整场景下的归因控制”，例如：

> 一种面向证据不完整场景的 APT 归因可判定性评估与大语言模型受控解释方法。

或者：

> 一种基于证据充分性门控的 APT 分层归因、拒答控制与缺失证据生成方法。

更长的专利题名可暂定为：

> 一种面向证据不完整场景的多源安全证据自适应融合与大语言模型辅助 APT 归因解释方法。

但权利要求的核心必须落在：

- 证据可用性画像；
- 证据充分性评分；
- 证据区分度评分；
- 冲突/伪旗风险检测；
- 归因粒度自适应降级；
- 拒答或暂缓归因；
- 缺失证据需求生成；
- LLM 受控解释与证据账本约束。

## 5. 二次复核清单

拿到 APT-ATT 后，优先核查以下问题：

| 核查点 | 若 APT-ATT 已覆盖 | Project05 应如何避让 |
|---|---|---|
| 是否做 evidence weighting | 若已覆盖证据权重 | 转向 sufficiency gate、calibration、refusal |
| 是否做 incomplete evidence ablation | 若已系统评估缺证据 | 转向缺失证据需求生成和归因粒度降级 |
| 是否支持 unknown actor / open-set | 若已支持 | 转向证据层级可判定性与合规解释 |
| 是否检测 false flag / mimicry | 若已覆盖 | 强化冲突证据和伪旗风险的证据账本机制 |
| 是否输出 confidence score | 若已覆盖 | 强化校准误差、过度归因率、拒答正确率 |
| 是否限制 LLM 只能引用证据 | 若已覆盖 | 强化证据账本、引用覆盖率和忠实性评价 |

## 6. 当前结论

APT-ATT 未获取是风险，不是阻塞。

当前工作应继续推进到：

1. 固定最终选题边界；
2. 写专利权利要求草案；
3. 设计证据不完整实验；
4. 保留 APT-ATT 二次撞题复核入口。
