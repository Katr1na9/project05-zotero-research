# 中文专利权利要求红线分析 - 2026-07-05

## 目的

本文件只分析中文专利红线，重点判断 Project05 后续若写专利，哪些技术表述必须避开。

当前重点中文专利：

1. `CN120110776B`：一种针对攻击模式的攻击手法聚类与归因方法。
2. `CN118646607A`：一种基于 APT 知识图谱关联数据的大语言模型增强方法。

## 1. CN120110776B

### 基本信息

- 专利号：CN120110776B
- 题名：一种针对攻击模式的攻击手法聚类与归因方法
- 本地红线笔记：`../02-literature-notes/2025-CN120110776B-Attack-Pattern-Clustering-Attribution-Patent.md`
- 本地 HTML：`../07-zotero-exports/pdfs_20260705_round3/CN120110776B_zh.html`

### 独立权利要求核心链路

该专利的权利要求 1 覆盖一条完整归因流程：

```text
威胁情报原始数据
  -> 规范化处理
  -> 基于开源网络安全知识图谱本体设计 LLM 提示词
  -> LLM 提取攻击信息
  -> RAG 框架补充上下文
  -> 生成实体属性三元组
  -> 三元组与网络安全知识图谱融合
  -> 获得 TTPs 数据
  -> 自编码器学习 TTP 深层特征
  -> 高斯混合聚类
  -> 结构熵增强聚类鲁棒性
  -> 生成生命周期阶段攻击向量
  -> 构建攻击树
  -> attention 为攻击树节点分配权重
  -> 攻击树相似度匹配
  -> 得到攻击组织/归因结果
```

### 从属权利要求覆盖点

该专利进一步覆盖：

- 威胁情报来源包括威胁情报报告、安全日志、论坛博客。
- 对长情报内容分割为小段语义单元，并对相似语义归一化。
- RAG 使用外部知识库实时检索，并把检索结果作为上下文给生成模型。
- 自编码器学习 TTPs 深层特征表示。
- 以 14 个 MITRE ATT&CK tactic 阶段作为聚类类型。
- 使用 TTP 节点局部 k 跳子图的结构熵。
- 当结构熵大于阈值时忽略该 TTP 节点，以提升聚类鲁棒性。
- 攻击树属性信息包括恶意软件、漏洞、工具规模、活动持续时间、发起战役个数。
- 只有攻击树相似度超过阈值时，才把知识图谱中的攻击组织作为根节点并输出归因。

### 对 Project05 的红线

Project05 专利不能写成以下方向：

1. `LLM + RAG + KG + TTP + attack tree + attribution`。
2. 从威胁情报抽取攻击信息并生成三元组，再融合知识图谱做归因。
3. 对 TTP 数据做聚类，然后基于 ATT&CK 生命周期阶段构建攻击向量。
4. 用攻击树相似度匹配获得攻击组织。
5. 用 attention 给攻击树节点分权重后做归因。
6. 用结构熵筛选 TTP 节点以增强聚类鲁棒性。

### Project05 可避让空间

如果写 Project05，必须避开“攻击手法聚类/攻击树匹配归因”。

可保留但要具体化的方向：

- 不做攻击树匹配，而做证据可用性画像。
- 不把 TTP 聚类作为核心，而把 TTP 视为低/中强度证据通道之一。
- 不通过攻击树相似度输出攻击组织，而通过证据充分性门控判断是否允许输出 actor。
- 强调 open-set / unknown actor / false flag / mimicry 下的拒答或降级。
- 强调 CTI 证据与本地日志/provenance 证据之间的一致性或冲突，而非单纯 KG 融合。

## 2. CN118646607A

### 基本信息

- 公开号：CN118646607A
- 题名：一种基于 APT 知识图谱关联数据的大语言模型增强方法
- 本地红线笔记：`../02-literature-notes/2024-CN118646607A-APT-KG-LLM-Enhancement-Patent.md`
- 本地 HTML：`../07-zotero-exports/pdfs_20260705_round3/CN118646607A_zh.html`

### 独立权利要求核心链路

权利要求 1 覆盖：

```text
收集网络安全领域相关数据
  -> 基于 APT 攻击特点构建 APT 知识图谱
  -> 根据用户输入问题查询 APT 知识图谱
  -> 利用查询到的数据片段生成增强提示
  -> 大语言模型生成更准确、更深入的回答
```

### 从属权利要求覆盖点

该专利进一步覆盖：

- APT 知识图谱本体设计与建模。
- 实体、属性、关系定义。
- 数据来源包括公共威胁情报平台、漏洞数据库和安全报告。
- 大语言模型接收用户问题并提取关键实体。
- 在 APT 知识图谱中定位相关节点。
- 探索邻居节点并设计查询语句查找节点关系。
- 汇总节点、邻居节点和关系信息形成数据集。
- 对数据集分割为独立数据片段。
- 对数据片段向量化并存入向量空间数据库。
- 检索与查询最相关的数据片段形成上下文。
- 使用 LangChain。
- 使用 LangChain QA Chain 把数据片段与用户问题合并，形成上下文感知提示。

### 对 Project05 的红线

Project05 专利不能写成以下方向：

1. `APT 知识图谱 + 大语言模型增强问答/分析`。
2. APT KG 查询后生成上下文提示给 LLM。
3. KG 节点/邻居/关系信息切片、向量化、入库、检索后做 LLM QA。
4. 使用 LangChain / QA Chain 组织 APT KG 增强问答。
5. 声称通过 APT KG 减少 LLM 幻觉、提升回答准确性和解释性，作为核心创新。

### Project05 可避让空间

如果 Project05 用知识图谱，必须把它降级为证据来源，而不是核心发明点。

可保留方向：

- APT KG 只是 evidence channel。
- 核心不是“问答增强”，而是“证据是否足以支持归因结论”。
- 不强调生成更准确回答，而强调当证据不足时拒绝高置信 actor 归因。
- 输出不只是回答，还包括：缺失证据类型、冲突证据、归因粒度、补充取证建议。
- 明确处理 open-set / false flag / mimicry，而 CN118646607A 没有覆盖这些。

## 3. 两个中文专利对 Project05 的共同限制

两个中文专利共同压缩了以下空间：

| 技术方向 | 是否被明显覆盖 | 说明 |
|---|---|---|
| APT KG + LLM | 是 | CN118646607A 已覆盖 APT KG 查询增强 LLM |
| LLM + RAG + 三元组 | 是 | CN120110776B 覆盖 RAG 生成实体属性三元组 |
| KG 融合威胁情报 | 是 | 两者都涉及图谱构建/融合 |
| TTP 聚类 | 是 | CN120110776B 覆盖 TTP 深层特征、自编码器、高斯混合聚类 |
| 攻击树归因 | 是 | CN120110776B 覆盖攻击树构建和相似度匹配 |
| attention 权重归因 | 是 | CN120110776B 覆盖攻击树节点权重分配 |
| LLM 增强回答 | 是 | CN118646607A 覆盖上下文感知提示和回答增强 |

## 4. Project05 专利避让建议

后续专利题名和权利要求应避免出现以下中心组合：

```text
LLM + RAG + KG + TTP + attack tree + attribution
APT KG + LLM enhanced QA
TTP clustering + attack organization attribution
```

更可防守的技术问题应改成：

> 在证据不完整、证据冲突、候选行为体难以区分或存在模仿/假旗风险时，如何判断当前证据是否足以支持高置信 APT 行为体归因，并在不足时进行降级或拒答。

推荐的 Project05 保护点：

1. 证据可用性画像：标记 CTI、IOC、malware、infrastructure、timeline、provenance/log 等证据的有无、粒度和可靠性。
2. 证据区分度评分：判断证据是否 generic、是否被多个 actor 共享、是否容易 mimicry。
3. 归因粒度门控：actor、campaign、intent、technique 四级门控。
4. 拒答/暂缓归因触发：证据不足、证据冲突、open-set、false flag、TTP mimicry 时触发。
5. 缺失证据解释：说明缺什么证据才能从低层结论升级到 actor attribution。

## 5. 当前结论

中文专利层面，`APT KG + LLM` 和 `LLM/RAG/KG/TTP/攻击树归因` 已经不能作为 Project05 的核心创新。

Project05 若要写专利，必须从“归因模型”转向“归因前的证据充分性门控与拒答/降级机制”。
